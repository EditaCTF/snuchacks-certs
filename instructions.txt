===============================================
  SNUC HACKS CERTIFICATE SIGNER
===============================================

Adds Santhi Ma'am's signature (visible stamp + PKCS#7) to cert PDFs
that already have Padmavathi Ma'am's stamp.

    pip install -r requirements.txt
    python sign.py -i staged -o signed \
                   -f santhi.png -p certificate.p12 -s PASSWORD

Input and output folders expect participants/, finalists/, volunteers/
subdirectories. Adjust SIG_BOX at the top of sign.py to re-position
the stamp (PDF points, y=0 = bottom).

Windows notes:
- venv\Scripts\activate (not source venv/bin/activate)
- Single-line invocations in cmd.exe
- If endesive install fails: pip install --no-deps endesive
  then pip install asn1crypto oscrypto python-dateutil
